# Agent Link reserved-screen turns

The owner needs Claude and Codex to take turns using one selected screen while ordinary owner activity continues. The current owner-away policy interrupts work when the owner returns. The shared queue has to remain visible to both the owner and the caller and give the owner a direct reclaim path.

The first release targets qualified, dedicated local project previews and explicitly scoped documents. The highest-risk outcomes are owner input interference, unintended scope disclosure, concurrent injectors and duplicate actions following an uncertain result. Authenticated work stays with Antechamber. Physical input, arbitrary apps, VM and hybrid identity designs remain outside this increment. Scope and proof obligations are in the [specification](../docs/specifications/reserved-screen-v1.md).
