# Factory shared reserved-screen Computer Use

Revision 1. Implementation contract for the accepted owner direction. Activation requires the release evidence below.

The Factory operating specification retains its existing access, authority, capacity, recovery and release controls. Its shared desktop rule is amended by the following requirements. Exact base, owner decisions, budget, private reviewer return and effective amendment record are maintained by Factory management.

**FOS-SEC-03 — Shared Computer Use.** Factory agents performing host desktop Computer Use MUST obtain a turn through the shared Agent Link queue and use the qualified Vercel agent-desktop route. GUI Queue shows the selected display, waiting, active, blocked, settling and terminal work and offers cancellation and owner reclaim. The operator MUST prebind the owner-selected left 24-inch portrait display using verified persistent identity and current geometry. Setup does not require repeated owner intervention. Execution status, progress and terminal outcomes MUST remain visible in the caller conversation and GUI Queue. The deterministic interface MUST NOT create another delegation layer.

**FOS-CU-01 — Concurrent owner work.** Qualified background semantic actions MAY run while the owner is active. They MUST preserve the owner's foreground application, keyboard recipient, pointer and clipboard within the verified route contract. A reserved monitor shares the host input seat. Unsupported work MUST report a concrete blocker. Foreground activation and global input are outside this route. Physical input requires distinct owner authority.

**FOS-CU-02 — Turn exclusivity and revocation.** A single broker MUST serialize desktop turns across hosts. Each action MUST bind task, connection, epoch, process lifetime, window, scope, operation and fresh observation. Invalid, changed or unknown bindings MUST refuse. Reclaim MUST durably close admission immediately and show settling for an already-issued semantic command. Completed reclaim or admission of another holder MUST wait for proven quiescence of all prior effect-capable actors. Wrapper exit, elapsed lease time and successful signal delivery are insufficient. Internal effects of already-issued commands remain attributed to those commands.

**FOS-CU-03 — Recovery and truthful outcomes.** Persist action intent before dispatch. Expose ticket, authority, delivery, effect and settling state separately. Uncertain delivery MUST NOT trigger a blind retry. Verification uses fresh permitted observation and independent effect evidence. Transport interruption alone does not prove requester loss. Loss or expiry closes stale authority without automatically adopting its task. Recovery MUST retain its accountable manager and return path.

**FOS-CU-04 — Scoped execution and observation.** Enforce scope before disclosure or emission. Caller-supplied identity, MCP labels, screen content and model instructions cannot grant authority. Authenticated browser work retains Antechamber's identity and read/effect authority. The desktop route admits only owned windows, approved read/effect grants and qualified exact builds. Broad app enumeration, whole-desktop screenshots, global menus and native system panels are outside the admitted catalog. Use cooperative same-user containment with documented boundaries.

**FOS-CU-05 — Loaded-host adoption.** Claude and Codex MUST expose the same supported deterministic contract, with evidence from actual loaded sessions and runtime refusal of obsolete mutation paths. Other Factory harnesses MUST be inventoried and verified or held from driving. Cutover requires one writer and reconciliation of legacy queued and running work. Unknown effect-capable actors prevent activation. Rollback closes new admissions and preserves historical and uncertain work.

**FOS-CU-06 — Release evidence.** Acceptance requires Logic, Regression, independent review, low-context WF, exact installed identities and handoff in both directions between Claude and Codex during concurrent owner activity. Verify display confinement, foreground focus, keyboard recipient, pointer and clipboard separately. Measure observer blind spots with negative controls. Human comfort requires a separate human observation. Merge through a reviewed PR and promote the exact clean origin/main build. Close the RFC only after release evidence reconciles every mandatory finding.
